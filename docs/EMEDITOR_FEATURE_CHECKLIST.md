# Mac 版 EmEditor 功能对照清单

目标：以 SiftEditor 为基础，逐步实现个人常用的 EmEditor 工作流。对照来源：[EmEditor 中文功能列表](https://zh-cn.emeditor.com/text-editor-features/)；基线为当前 SiftEditor `main`（1.24.1）。本表记录功能行为，不表示要复制 EmEditor 的名称、界面或代码。

## 勾选规则

- `[x]`：当前开源版已有相应能力，且已在源码/现有测试或实际使用中确认**本条所写的范围**。不代表与 EmEditor 全部选项等价。
- `[ ]`：尚无、仅部分实现，或尚未通过本条验收。完成一项后才改为 `[x]`，并在末尾“验收记录”写版本、测试数据与结果。
- 每条只描述一个可验收能力。更复杂的功能另拆子项；不能因为有同名菜单就打勾。
- 大文件操作至少用 1 GB 原始样本和 5 GB 测试副本验证；涉及修改时只操作副本，并核对保存前后数据。重新生成副本前检查空间。

## 一、文件与大文件基础

- [x] 打开并浏览多 GB 本地文本文件（已在本机打开约 5 GB 测试副本；当前副本位于 `testdata/test_5gb.sql`）。
- [x] 大文件按行跳转、滚动与后台行索引。
- [x] 大文件局部编辑与保存的代码路径及现有测试。
- [ ] 5 GB 文件编辑、撤销、保存、重新打开后的端到端数据校验。
- [x] 保存前写临时文件并原子替换。
- [x] UTF-8、Shift-JIS、EUC-JP 的读取与保存选择。
- [x] LF/CRLF 行尾处理。
- [x] 多文档打开、最近文件与会话恢复。
- [x] 文件增长时跟随尾部（Follow）。
- [x] gzip/zip 与标准输入流打开。
- [ ] 大文件控制器：按字节/行范围打开、分割与合并，并保持源文件安全。
- [ ] 二进制模式下查看、搜索、编辑与保存。
- [ ] 多文件批量转码，并提供逐文件失败报告。

## 二、搜索、筛选与替换

- [x] 查找窗口统一为 EmEditor 对照布局；现有功能可操作，未实现选项显示但禁用。
- [x] 当前文档普通/正则搜索、匹配数及前后跳转。
- [x] 按匹配行筛选显示，并保留原始行号。
- [x] 当前文档替换及撤销的现有代码路径。
- [ ] 5 GB 文件全量替换的结果校验、取消与失败恢复。
- [ ] EmEditor 式批次替换：多条规则顺序执行、预览、一次撤销。
- [ ] 查找和替换中的数值范围表达式。
- [ ] 模糊匹配及明确的匹配范围与排序规则。
- [ ] 跨文件夹查找及替换；结果定位、预览与失败报告（开源版）。
- [x] 查找栏提取匹配整行到新文档；选项支持前后附加行、分组分隔符和常用整行计数。
- [ ] 搜索结果中提取匹配文本到新文档并去重/计数（匹配片段模式、忽略词等）。
- [ ] 标记匹配、保存标记集并对标记行批量操作。

- [x] 选区内行排序、删除重复行、反转、编号与缩进。
- [ ] 全文/筛选结果排序与去重，支持多 GB 文件及进度取消。
- [x] 提取常用整行，输出“内容、次数”并可按次数排序。
- [x] 提取常用单词、正则匹配、IPv4/IPv6、邮箱、HTTP(S) 网址并计数。

- [x] 频次提取支持忽略词、大小写及结果行数上限。

- [ ] 频次提取支持选区、筛选结果及搜索组内所有文档。
- [ ] 频次提取支持制表符、分号、管道符等其他输出格式。
- [ ] Unicode 规范化、半角/全角转换与字符代码检查。

- [ ] 冻结标题、列显示/隐藏、列宽及列顺序管理。
- [ ] 按单列/多列排序，支持数字、日期、空值和稳定排序。
- [ ] 按指定列提取、去重、统计及导出。
- [ ] 删除重复记录，支持按指定列判重。
- [ ] 合并/拆分列与合并行。
- [ ] 插入、删除、编号及自动填充行/列。
- [ ] 快速填充和转置。
- [ ] 按键连接两个 CSV 文件（Join）。
- [ ] 数据透视表：分组、聚合及导出。
- [ ] 嵌套 CSV 与字段内换行的解析、编辑、保存验收。
